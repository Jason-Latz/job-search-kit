# profile/: what you actually did and want

The source of truth about you, richer than any resume. Resumes, form answers, cover
letters, outreach and interview prep all draw from here, so a new Claude session can
tailor without re-interviewing you.

- `about-me.md`: a ~150-word summary. The daily ranking step reads it.
- `search-preferences.md`: what you want, ranked; what you never want; standard form answers.
- `experience/<entry>.md`: one file per job, research role or project, named like the
  matching `resume/content/` file, from `experience/_template.md`.

Never promote an interpretation or a framing to a verified fact without you saying so.
Approximate numbers stay marked as approximate.
